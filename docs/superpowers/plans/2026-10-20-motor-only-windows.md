# 电机控制与 Windows 调试整理

目标：保留 ESP32-S3 双电机、编码器、PID、运动控制；其他功能源码保留并暂时禁用。在 Windows 编译、烧录、串口调试。

- [x] 用默认开启的 CMake 开关隔离其他组件及其托管依赖；通过条件编译保留原有启动、外设、全局变量代码。
- [x] 解除控制任务的 IMU 依赖，使用编码器航向；保留原有电机引脚和机械参数。
- [x] 提供串口轮速、停车、PID、状态命令；校验有限值及范围，上电静止，2 秒无运动命令停车。
- [x] 提供 Windows 环境加载脚本和操作说明，使用独立构建目录。
- [x] 实际构建固件并检查编译清单、链接符号、差异；不自动烧录或驱动实物。
- [x] 后续补充：同一调试串口以 FireWater 50 Hz 发送左右实测轮速；使用无回显行接收避免终端探测和提示符干扰，vofa 0/1 切换。

验证重点：默认构建不依赖 micro-ROS/网络/传感器；禁用 IMU 后不能把固定零航向用于转向闭环；控制对象由运动任务独占；串口输入错误不下发指令；Windows 脚本传播失败退出码。

验证记录（2026-10-20）：Windows ESP-IDF 5.5.3 实际构建通过（脚本 build）；源文件清单仅含 8 个 main 电机相关源文件；组件和 ELF 符号检查确认非电机任务未链接；省略串口号时 flash 在访问设备前失败并返回 1；git diff --check 通过。固件生成于 build_windows/。未进行开发板烧录、轮速标定或 VOFA+ 实物采集，超时、命令输入及实时输出尚需在开发板验证。
